# yd 实施计划：i18n 的实时渲染、热路径性能与异常处理

> 需求来源（用户原话）：
> 「i18n在实时渲染、高性能替换、异常处理等问题进行修复、优化」

## 0. 需求差异说明

只读需求基线未涵盖本节，本文件即差异说明。

## 1. 现状：热路径上的四笔开销

`Translator.T(key, args...)` 每次调用依次付出：

| # | 开销 | 位置 |
|---|---|---|
| 1 | **RWMutex 读写锁** | `Bundle.lookup` 每次翻译都 `RLock` |
| 2 | **按键点分拆分的分配** | `drill` 每层 `strings.Split` |
| 3 | **嵌套 map 逐层下钻 + 接口装箱** | `drill` 走 `map[string]any` |
| 4 | **占位符解析 + Builder/Sprintf 分配** | `interpolate` / `fillNamed` |

一页模板渲染几十次翻译，这四笔开销是相乘的。`Reload` 目前是整表替换（在锁内），
实时性本身没问题，但读路径被同一把锁串行化。

## 2. 设计

### 2.1 加载期预编译，运行期只做一次查表

**在 `load`/`Reload` 时**把嵌套目录**扁平化**并**预编译每条消息**：

```go
type segment struct {
    literal string   // 字面量片段
    arg     int      // 占位符序号；-1 表示这是字面量
}
type message struct {
    raw      string     // 原文，用于回退与诊断
    segments []segment  // nil 表示「无占位符」的最快路径
    verbs    int        // printf 动词个数（0 表示不做 Sprintf）
}
```

- 查找：**一次 `map[string]message` 命中**，不再分层下钻、不再拆键；
- 渲染：无占位符的消息**直接返回预存字符串**（零分配、零格式化）——这是绝大多数；
- 有占位符：按段追加到**池化缓冲**（`core/bufpool`），最后一次 `string()` 转换。

### 2.2 读路径无锁

- `Bundle` 用 **`atomic.Pointer` 持有一张不可变的表**，`Reload` 构建新表后**整表原子替换**；
  读路径**不加锁**。保证读到的要么是旧表、要么是新表，**绝不会是半更新的状态**。
- 这同时改善"实时渲染"：语言切换与热重载后，下一次翻译立即看到新表。

### 2.3 异常处理

| 场景 | 现状 | 改为 |
|---|---|---|
| **格式参数类型不匹配**（`%d` 传字符串） | `fmt.Sprintf` 输出 `%!d(string=x)`——**把 Go 的调试语法直接呈现给终端用户** | **类型检查后再渲染**；不匹配时**回退到原始消息**，并**计数 + 首次 Warn**（带 key） |
| 占位符数量不足 | 保留未填充占位符 | 保留（现状合理），加断言 |
| `{{` 未闭合 | 原样保留 | 保留，加测试 |
| 未知 key | 返回 key 本身 | 返回 key，但**累加 Miss 计数并通过钩子上报**——否则线上缺翻译无人知晓 |
| nil Translator / nil Bundle | 返回 key | 保持 |
| 语言文件缺失 / YAML 畸形 | `New` 返回错误 | 保持，错误用 `errx` 哨兵 |

### 2.4 需要保持的既有契约

- `T` 仍是 `func(string, ...any) string`，可直接注册为模板函数；
- 回退链「当前语言 → 默认语言 → key 本身」不变；
- 支持 `{{.Name}}` 与 printf 两种占位风格（顺序填充语义不变）；
- `Reload` 失败时**保留旧表**（不能因为一次坏文件把线上翻译清空）。

## 3. 测试与基准

**正确性**：
- 扁平化前后**所有既有用例结果一致**（这是重构的安全底线）；
- 深层嵌套键、大小写归一、数组/映射叶子不算消息；
- `Reload` 并发进行时，翻译结果要么全旧要么全新（用 `-race` + 交替 Reload 断言）；
- 参数不匹配回退原文、缺翻译计数、未闭合占位符。

**性能**（`-benchmem -count=6`，取中位数）：
- `BenchmarkT/miss`、`/no_args`、`/named`、`/verbs`、`/fallback_lang`；
- 目标：**无占位符路径 allocs/op = 0**；有占位符路径 allocs/op ≤ 1；
- 对比改造前后的 ns/op；**没有实测提升的不合并**。

## 4. 验收

1. 既有 i18n 与模板渲染测试全绿（行为不变）；
2. 读路径无锁（代码可见 `atomic.Pointer`，无 `RLock` 在热路径上）；
3. 无占位符翻译 `allocs/op == 0`；
4. 参数类型不匹配不再输出 `%!d(...)`，而是原文 + 计数；
5. `Reload` 失败保留旧表；并发 Reload 无 `-race` 报告；
6. 全仓门禁全绿。

## 5. 已知取舍

- **预编译后 `Reload` 成本略升**：加载期多一次扁平化与分段，但这是冷路径，换来热路径的常数级查找。
- **不做翻译结果缓存**：消息本身就是预编译的，再套一层 LRU 只会增加维护面与失效风险。
- **未命中仍返回 key**：这是既有契约（保证不 panic、便于定位），不改成空串。
